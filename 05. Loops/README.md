## 📚 Content Overview

This section covers the following loop constructs in Python:

### 1. For Loop
- Iterates over a sequence (e.g., list, tuple, string, or range)
- Syntax: `for variable in iterable:`
- Example: Looping through a list of numbers or characters in a string

### 2. While Loop
- Repeats as long as a condition is true
- Syntax: `while condition:`
- Example: Running a loop until a counter reaches a specific value

### 3. Nested Loops
- Loops within loops for handling multi-dimensional data
- Example: Iterating through a matrix or generating patterns

### 4. Loop Control Statements
- **Break**: Exits the loop prematurely
- **Continue**: Skips the current iteration and proceeds to the next
- **Pass**: Placeholder that does nothing (used for empty loops)
