## 📚 Content Overview

This section covers the following aspects of regular expressions in Python:

### 1. Introduction to Regex
- **What is Regex?**: A sequence of characters that defines a search pattern
- **Python Module**: Using the `re` module for regex operations
- **Common Use Cases**: Text searching, validation, splitting, and substitution

### 2. Basic Regex Patterns
- **Literals**: Matching exact characters (e.g., `abc`)
- **Metacharacters**: Special characters like `.`, `*`, `+`, `?`, `|`, `^`, `$`
- **Character Classes**: `[a-z]`, `[0-9]`, `\w`, `\d`, `\s`
- **Anchors**: `^` (start of string), `$` (end of string)
- **Groups**: Using parentheses `()` for capturing groups

### 3. Common Regex Functions
- **`re.match()`**: Checks for a match at the start of a string
- **`re.search()`**: Searches for the first match in a string
- **`re.findall()`**: Returns all non-overlapping matches as a list
- **`re.finditer()`**: Returns an iterator of match objects
- **`re.sub()`**: Replaces matches with a specified string
- **`re.split()`**: Splits a string based on a regex pattern

### 4. Advanced Regex Concepts
- **Greedy vs. Non-Greedy Matching**: `*?`, `+?`, `??`
- **Lookaheads and Lookbehinds**: `(?=...)`, `(?!...)`, `(?<=...)`, `(?<!...)`
- **Backreferences**: Reusing captured groups (e.g., `\1`, `\2`)
- **Flags**: `re.IGNORECASE`, `re.MULTILINE`, `re.DOTALL`
