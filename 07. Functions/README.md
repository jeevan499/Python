# 🧮 Functions in Python

Welcome to the **Functions in Python** section of the Python Learning Repository! This folder provides a comprehensive guide to Python's functions, their syntax, and practical examples to help you understand how to create and use them effectively in your programs. Whether you're a beginner or refining your skills, this resource will enhance your understanding of Python's function system.

---

## 📚 Content Overview

This section covers the following aspects of functions in Python:

### 1. Defining Functions
- Basic function syntax: Using `def` to create functions
- Function with no parameters: Simple functions without arguments
- Function with parameters: Passing arguments to functions
- Default parameters: Setting default values for arguments
- Keyword arguments: Specifying arguments by name

### 2. Return Statements
- Using `return` to output values
- Returning multiple values: Using tuples or other data structures
- Functions without `return`: Implicitly returning `None`

### 3. Function Types
- **Named Functions**: Standard functions defined with `def`
- **Anonymous Functions (`lambda`)**: Single-line functions for simple operations
- **Recursive Functions**: Functions that call themselves
- **Higher-Order Functions**: Functions that accept or return other functions (e.g., `map()`, `filter()`)

### 4. Scope and Lifetime
- **Local Scope**: Variables defined inside a function
- **Global Scope**: Variables defined outside functions
- **Nonlocal Scope**: Variables in nested functions
- Using `global` and `nonlocal` keywords

### 5. Advanced Function Concepts
- **Decorators**: Wrapping functions to extend behavior
- **Closures**: Functions retaining access to variables from their enclosing scope
- **Function Annotations**: Adding type hints to parameters and return values
- **Variable-Length Arguments**: Using `*args` and `**kwargs`
