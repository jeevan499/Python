## 📚 Content Overview

This section covers the following conditional statements in Python:

### 1. If Statement
- Basic `if` statement: Execute code if a condition is `True`
- Syntax: 
  ```python
  if condition:
      # code block
  ```

### 2. If-Else Statement
- `if-else`: Execute one block if the condition is `True`, another if `False`
- Syntax:
  ```python
  if condition:
      # code block for True
  else:
      # code block for False
  ```

### 3. If-Elif-Else Statement
- `if-elif-else`: Handle multiple conditions
- Syntax:
  ```python
  if condition1:
      # code block for condition1
  elif condition2:
      # code block for condition2
  else:
      # code block if all conditions are False
  ```

### 4. Nested If Statements
- Using `if` statements within other `if` statements
- Syntax:
  ```python
  if condition1:
      if condition2:
          # nested code block
  ```

### 5. Ternary Operator (Conditional Expression)
- Compact `if-else` in a single line
- Syntax:
  ```python
  value = true_value if condition else false_value
  ```
