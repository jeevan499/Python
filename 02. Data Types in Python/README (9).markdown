## 📚 Content Overview

This section covers the following Python data types:

### 1. Numeric Types
- **Integer (`int`)**: Whole numbers (e.g., `42`, `-10`)
- **Float (`float`)**: Decimal numbers (e.g., `3.14`, `-0.001`)
- **Complex (`complex`)**: Numbers with real and imaginary parts (e.g., `3 + 4j`)

### 2. Sequence Types
- **String (`str`)**: Ordered sequence of characters (e.g., `"Hello, Python!"`)
- **List (`list`)**: Ordered, mutable collection (e.g., `[1, 2, 3]`)
- **Tuple (`tuple`)**: Ordered, immutable collection (e.g., `(1, 2, 3)`)

### 3. Set Types
- **Set (`set`)**: Unordered collection of unique elements (e.g., `{1, 2, 3}`)
- **Frozen Set (`frozenset`)**: Immutable version of a set (e.g., `frozenset([1, 2, 3])`)

### 4. Mapping Type
- **Dictionary (`dict`)**: Key-value pairs (e.g., `{"name": "Alice", "age": 25}`)

### 5. Boolean Type
- **Boolean (`bool`)**: Represents `True` or `False`

### 6. None Type
- **NoneType (`None`)**: Represents the absence of a value

## 🔍 Key Concepts Covered

- **Type Checking**: Using `type()` and `isinstance()` to identify data types
- **Type Conversion**: Converting between types (e.g., `int("123")`, `str(42)`)
- **Mutability**: Understanding mutable (e.g., `list`, `dict`) vs. immutable (e.g., `tuple`, `str`) types
- **Common Operations**: Methods and operations specific to each data type (e.g., `list.append()`, `str.upper()`)
- **Examples**: Practical code snippets demonstrating real-world usage
